# `.agents` — Orientações para IA

Esta pasta centraliza a documentação de contexto e as orientações utilizadas pelos agentes de inteligência artificial durante o desenvolvimento do projeto **Programando o Futuro**.

O objetivo é fornecer uma referência única para que os agentes compreendam o projeto, respeitem as decisões da equipe e sigam as regras estabelecidas.

## Estrutura

```text
.agents/
├── README.md
└── CONTEXTO.md
```

## Arquivos

| Arquivo | Responsabilidade |
|---|---|
| `CONTEXTO.md` | Documento central do projeto. Reúne informações, objetivos, regras, restrições, hipóteses, pendências e orientações para os agentes. |
| `README.md` | Apresenta a finalidade e a organização desta pasta. |

## Diretrizes para os agentes

- Consultar o `CONTEXTO.md` antes de executar qualquer tarefa relacionada ao projeto.
- Respeitar todas as regras, restrições e orientações estabelecidas no documento.
- Não inventar informações, decisões, dados ou resultados de pesquisas.
- Diferenciar informações confirmadas, hipóteses e questões pendentes.
- Perguntar à equipe sempre que uma informação necessária não estiver definida.
- Não modificar decisões ou diretrizes do projeto sem autorização.

## Manutenção

O `CONTEXTO.md` deve ser atualizado conforme novas decisões forem tomadas, pesquisas forem realizadas e informações forem confirmadas pela equipe.

Evite duplicar informações entre documentos. O contexto e as regras devem permanecer centralizados no `CONTEXTO.md`, que funciona como referência principal para os agentes de IA.
